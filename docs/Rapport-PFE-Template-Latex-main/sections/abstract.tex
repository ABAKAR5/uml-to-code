This project focuses on the development of a web platform entitled \textbf{UML-to-Code}, designed to automate the transition between the design phase (UML) and the software development phase. The application allows developers to submit class diagrams in various formats (XMI, PNG/JPG, PDF) and instantly generate structured source code in Python or PHP, as well as a complete Flask server.

The major innovation of this solution lies in the integration of generative Artificial Intelligence (via Groq Llama 3.3-70b), enabling intelligent analysis of diagram images, thus complementing the traditional algorithmic approach based on XMI parsing. The results show a significant time saving in setting up the basic structures of IT projects.
