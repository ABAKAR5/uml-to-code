\section*{Bilan du projet}

Au terme de ce projet, nous avons conçu et développé \textbf{UML-to-Code}, une application web full-stack innovante permettant de transformer automatiquement des diagrammes de classes UML en code source fonctionnel, grâce à l'intégration de l'Intelligence Artificielle générative \textbf{Groq Llama 3.3-70b}\footnote{Documentation API Groq : \reporturl{https://console.groq.com/docs}}.

Le projet a été mené à bien en respectant le planning initial basé sur le \textbf{modèle incrémental}, avec 5 incréments étalés sur trois semaines. L'ensemble des objectifs fixés au départ ont été atteints :

\begin{itemize}
    \item \textbf{Formats d'entrée multiples} : l'application accepte les fichiers XMI, les images PNG/JPG et les documents PDF
    \item \textbf{Génération de code} : le code Python et PHP généré est syntaxiquement correct, complet avec constructeurs, getters, setters et gestion de l'héritage
    \item \textbf{Serveur Flask automatique} : les routes CRUD sont générées automatiquement pour chaque classe détectée
    \item \textbf{Interface moderne} : Glassmorphism, Monaco Editor, historique local, mode sombre/clair, barre de progression, notifications toast et export ZIP
    \item \textbf{Déploiement en ligne} : frontend sur Vercel\footnote{Application : \reporturl{https://uml-to-code-peach.vercel.app}} et backend sur Render\footnote{API : \reporturl{https://uml-to-code.onrender.com}}
    \item \textbf{Open source} : dépôt GitHub public\footnote{Code source : \reporturl{https://github.com/ABAKAR5/uml-to-code}}
\end{itemize}

Les tests fonctionnels ont confirmé un taux de succès de génération supérieur à 95\,\%, avec des temps de réponse inférieurs à 5 secondes en mode IA Groq et inférieurs à 2 secondes en mode algorithmique, dépassant ainsi les critères d'acceptation fixés dans le cahier des charges.

\section*{Difficultés rencontrées}

La réalisation de ce projet n'a pas été sans difficultés. Parmi les principaux obstacles rencontrés :

\begin{itemize}
    \item \textbf{Migration de l'IA} : passage de Google Gemma vers Groq Llama 3.3-70b, réécriture du module client IA et adaptation des prompts
    \item \textbf{Parsing XMI} : variations de structure selon les exports StarUML, parsing robuste multi-namespaces
    \item \textbf{Caractères Unicode dans \LaTeX} : rédaction du cahier des charges avec encodage UTF-8 et packages adaptés
    \item \textbf{Déploiement CORS} : configuration des en-têtes entre Vercel et Render
    \item \textbf{Monaco Editor} : intégration React et affichage multi-lignes du code généré
\end{itemize}

\section*{Apports personnels}

Ce projet m'a permis d'acquérir et de consolider de nombreuses compétences :

\begin{itemize}
    \item \textbf{Techniques} : full-stack (React + Flask), API d'IA générative, déploiement cloud, rédaction \LaTeX
    \item \textbf{Méthodologiques} : cycle incrémental, modélisation UML, gestion de projet solo
    \item \textbf{Transversales} : gestion du temps, résolution de problèmes, documentation technique
\end{itemize}

\section*{Perspectives}

Bien que fonctionnelle et déployée, l'application offre des perspectives d'extension :

\begin{itemize}
    \item Nouveaux langages : Java, TypeScript, C\#, Dart
    \item Génération SQL automatique à partir des classes
    \item Autres diagrammes UML (séquence, activité, déploiement)
    \item Authentification et sauvegarde cloud des générations
    \item Plugin VS Code et fine-tuning d'un modèle spécialisé UML→code
\end{itemize}

En définitive, ce projet démontre que l'association de la modélisation UML et de l'IA générative constitue une voie prometteuse pour l'automatisation du développement logiciel. \textbf{UML-to-Code} est une contribution concrète, réalisée à l'INSTA Abéché et ouverte à la communauté via GitHub.
