\section*{Bilan du projet}

Au terme de ce projet, nous avons conçu et développé \textbf{UML-to-Code}, une application web full-stack innovante permettant de transformer automatiquement des diagrammes de classes UML en code source fonctionnel, grâce à l'intégration de l'Intelligence Artificielle générative \textbf{Groq Llama 3.3-70b}.

Le projet a été mené à bien en respectant le planning initial basé sur le \textbf{modèle incrémental}, avec 5 incréments étalés sur trois semaines. L'ensemble des objectifs fixés au départ ont été atteints :

\begin{itemize}
    \item \textbf{Formats d'entrée multiples} : l'application accepte les fichiers XMI, les images PNG/JPG et les documents PDF
    \item \textbf{Génération de code} : le code Python et PHP généré est syntaxiquement correct, complet avec constructeurs, getters, setters et gestion de l'héritage
    \item \textbf{Serveur Flask automatique} : les routes CRUD sont générées automatiquement pour chaque classe détectée
    \item \textbf{Interface moderne} : l'application propose une interface Glassmorphism avec Monaco Editor, historique local, mode sombre/clair, barre de progression, notifications toast et export ZIP
    \item \textbf{Déploiement en ligne} : l'application est accessible au monde entier via \href{https://uml-to-code-peach.vercel.app}{\texttt{uml-to-code-peach.vercel.app}}, avec le backend hébergé sur Render
    \item \textbf{Open source} : le code source complet est disponible sur GitHub à l'adresse \href{https://github.com/ABAKAR5/uml-to-code}{\texttt{github.com/ABAKAR5/uml-to-code}}
\end{itemize}

Les tests fonctionnels ont confirmé un taux de succès de génération supérieur à 95\%, avec des temps de réponse inférieurs à 5 secondes en mode IA Groq et inférieurs à 2 secondes en mode algorithmique, dépassant ainsi les critères d'acceptation fixés dans le cahier des charges.

\section*{Difficultés rencontrées}

La réalisation de ce projet n'a pas été sans difficultés. Parmi les principaux obstacles rencontrés :

\begin{itemize}
    \item \textbf{Migration de l'IA} : le passage initial de Google Gemma (API Gemini) vers Groq Llama 3.3-70b a nécessité une réécriture complète du module \texttt{GroqClient} et une adaptation des prompts
    \item \textbf{Parsing XMI} : la structure des fichiers XMI exportés depuis StarUML présente des variations selon les versions, ce qui a nécessité un parsing robuste gérant plusieurs namespaces
    \item \textbf{Caractères Unicode dans LaTeX} : la rédaction du cahier des charges en LaTeX a présenté des difficultés liées aux caractères spéciaux non supportés par pdflatex
    \item \textbf{Déploiement CORS} : la communication entre le frontend Vercel et le backend Render a nécessité une configuration précise des en-têtes CORS
    \item \textbf{Monaco Editor} : l'intégration de Monaco Editor dans React a demandé une gestion particulière du rendu et de l'affichage du code sur plusieurs lignes
\end{itemize}

\section*{Apports personnels}

Ce projet m'a permis d'acquérir et de consolider de nombreuses compétences techniques et méthodologiques :

\begin{itemize}
    \item \textbf{Compétences techniques} : maîtrise du développement full-stack (React + Flask), intégration d'API d'IA générative, déploiement cloud (Vercel + Render), rédaction de documents techniques en \LaTeX
    \item \textbf{Compétences méthodologiques} : application concrète du cycle de vie incrémental, modélisation UML (Use Case, Classes, Séquence), gestion de projet en solo
    \item \textbf{Compétences transversales} : gestion du temps, résolution de problèmes techniques complexes, documentation et communication technique
\end{itemize}

\section*{Perspectives}

Bien que fonctionnelle et déployée, l'application UML-to-Code offre de nombreuses perspectives d'amélioration et d'extension :

\begin{itemize}
    \item \textbf{Nouveaux langages} : ajouter la génération de code Java, TypeScript, C\# ou Dart (Flutter)
    \item \textbf{Génération SQL} : générer automatiquement les scripts de création de bases de données à partir des classes détectées
    \item \textbf{Support des autres diagrammes UML} : diagrammes de séquence, d'activité et de déploiement
    \item \textbf{Authentification} : ajouter un système de comptes utilisateurs avec sauvegarde des générations côté serveur
    \item \textbf{Collaboration} : permettre le partage de projets générés entre utilisateurs
    \item \textbf{Plugin IDE} : développer une extension VS Code intégrant directement UML-to-Code dans l'éditeur
    \item \textbf{Fine-tuning du modèle} : entraîner un modèle spécialisé sur des paires (diagramme UML, code) pour améliorer encore la qualité du code généré
\end{itemize}

\vspace{1cm}

En définitive, ce projet démontre que l'association de la modélisation UML et de l'Intelligence Artificielle générative représente une voie prometteuse pour l'automatisation du développement logiciel. \textbf{UML-to-Code} constitue une contribution concrète et opérationnelle dans cette direction, réalisée dans le cadre académique de l'INSTA Abéché, et ouverte à la communauté des développeurs via GitHub.
