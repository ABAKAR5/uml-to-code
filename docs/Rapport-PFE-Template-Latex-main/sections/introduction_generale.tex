\section*{Contexte et problématique}

Dans le domaine du Génie Logiciel, la modélisation UML\fnUML (\textit{Unified Modeling Language}) constitue une étape incontournable du cycle de développement logiciel. Elle permet aux développeurs et architectes de concevoir, documenter et communiquer l'architecture d'un système de manière standardisée, avant même d'écrire la première ligne de code. Cependant, le passage du modèle conceptuel UML au code source représente encore aujourd'hui une tâche manuelle, répétitive et souvent source d'erreurs et d'incohérences.

Cette problématique s'inscrit dans le cadre du \textbf{Développement Dirigé par les Modèles} (MDD — \textit{Model-Driven Development}), un paradigme qui préconise la génération automatique de code à partir de modèles de haut niveau. Malgré l'existence de plusieurs outils de transformation UML vers code, ceux-ci restent soit trop complexes à installer et à utiliser, soit limités à un seul langage cible, soit dépourvus de toute intelligence artificielle pour produire un code contextuel et exploitable directement.

\section*{Motivation}

L'émergence des modèles d'Intelligence Artificielle générative de grande taille (\textit{Large Language Models} — LLM) ouvre de nouvelles perspectives pour automatiser et enrichir ce processus de transformation. En exploitant la capacité de ces modèles à comprendre la structure d'un diagramme UML et à générer du code source cohérent, il devient possible de franchir un cap significatif dans l'automatisation du développement logiciel.

C'est dans ce contexte que s'inscrit le présent projet, réalisé dans le cadre du module de Mini-Projet de Soutenance de la troisième année en Génie Logiciel à l'Institut National Supérieur des Sciences et Techniques d'Abéché (INSTA), Tchad.

\section*{Objectifs}

Ce projet a pour objectif principal de concevoir et développer une application web full-stack, baptisée \textbf{UML-to-Code}, capable de transformer automatiquement un diagramme de classes UML en code source fonctionnel, en exploitant le modèle d'IA générative \textbf{Groq Llama 3.3-70b}\fnGroq.

Plus précisément, les objectifs visés sont les suivants :

\begin{itemize}
    \item Accepter plusieurs formats d'entrée : fichier XMI exporté depuis StarUML, image PNG/JPG, ou document PDF
    \item Générer du code source \textbf{Python} ou \textbf{PHP} complet avec classes, attributs, méthodes et relations d'héritage
    \item Générer automatiquement un \textbf{serveur Flask} avec les routes CRUD correspondantes
    \item Proposer une interface web moderne, intuitive et responsive avec un éditeur de code intégré (\textbf{Monaco Editor})
    \item Permettre l'export du projet complet en archive \textbf{ZIP} prête à déployer
    \item Déployer l'application en ligne\footnote{Vercel : \reporturl{https://uml-to-code-peach.vercel.app} ; Render : \reporturl{https://uml-to-code.onrender.com}} et la rendre accessible au grand public
\end{itemize}

\section*{Structure du rapport}

Ce rapport est organisé en trois chapitres principaux, encadrés par une introduction et une conclusion générales :

\begin{itemize}
    \item \textbf{Chapitre 1 — Étude préliminaire et analyse des besoins} : présente le contexte général du projet, l'analyse de l'existant, la problématique identifiée, les acteurs du système et les exigences fonctionnelles et non fonctionnelles.

    \item \textbf{Chapitre 2 — Conception et Modélisation} : décrit les choix de conception, le cycle de vie retenu, l'architecture globale du système, ainsi que les diagrammes UML de conception (Use Case, Classes, Séquence).

    \item \textbf{Chapitre 3 — Réalisation et Implémentation} : présente l'environnement de développement, les détails d'implémentation du backend et du frontend, le déploiement de l'application, ainsi que les tests et résultats obtenus.
\end{itemize}
