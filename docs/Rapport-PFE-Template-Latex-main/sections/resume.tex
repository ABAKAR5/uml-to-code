Ce projet porte sur le développement d'une plateforme web intitulée \textbf{UML-to-Code}, conçue pour automatiser la transition entre la phase de conception (UML) et la phase de développement d'un logiciel. L'application permet aux développeurs de soumettre des diagrammes de classes sous divers formats (XMI, PNG/JPG, PDF) et de générer instantanément du code source structuré en Python ou PHP, ainsi qu'un serveur Flask complet.

L'innovation majeure de cette solution réside dans l'intégration de l'Intelligence Artificielle générative (via Groq Llama 3.3-70b), permettant une analyse intelligente des images de diagrammes, complétant ainsi l'approche algorithmique classique basée sur le parsing XMI. Les résultats montrent un gain de temps significatif dans la mise en place des structures de base des projets informatiques.

\textbf{Mots-clés :} UML, Génération de code, Intelligence Artificielle, React, Flask, Llama 3.3, Génie Logiciel.
